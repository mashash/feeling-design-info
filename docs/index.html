言葉から、
見る・動かす体験へ。

Feeling Designは、BrainVaultで選んだ言葉と、対話で整理した要件から、参考の探索・デザイン・ウェブ実装をつなぐ、開発中のローカル制作アプリです。

Pinterest API連携は申請準備中です

本人の公開・非公開ボードを参照する接続を開発しています。取得情報の保存とOpenAIへの入力は、Pinterestに利用方法を明示し、必要な許可を確認してから有効にします。この案内ページからアカウントを接続したり、ピンやノートをアップロードしたりすることはできません。

The workflow

入力から制作までを、ひとつにつなぐ。

  1. 言葉と要件を定める

    利用者が接続したBrainVaultから選んだ言葉と、対話で確認した目的・読者・必要な情報を制作の土台にします。

  2. 参考を見て、選び、統合する

    スタイル、画面構成、動き、操作前後、材質の参考を照合し、何をどこへ取り入れるかを設計します。参考画像をそのまま完成品の素材へ転用することとは区別します。

  3. 画面全体の体験を設計する

    コードを書く前に、PCとスマートフォンの構図、奥行き、章の移り変わり、スクロールやカーソルへの反応を具体化します。読みやすさと動きを抑えた表示も扱います。

  4. 実装して、実画面で確かめる

    利用者が接続した制作AIが実装し、実際の画面と操作を確認して修正します。構想やテストの通過だけで、作品の完成を判定しません。

制作は利用者の環境で。

本体はローカルアプリです。BrainVaultと参照ライブラリの場所、制作AIの接続を利用者が管理します。認証情報を配布パッケージやAIへの入力へ含める設計ではありません。

参考と公開素材を分ける。

私有ノートや参考画像を完成ページへ自動で掲載しません。公開用に確認した文章・リンクと、使用できる制作素材を区別します。

For integration review

Feeling Design is a local design research and website-authoring app developed by ARCHECO. The planned Pinterest connection reads the authenticated owner’s public and secret reference boards. Selected images, attribution and observations would inform original designs through the owner’s connected OpenAI production agent. The application itself does not train models. API data retention and third-party processing require Pinterest’s explicit authorization and are not currently enabled.

This is the application’s dedicated information site. It does not provide Pinterest login, collect credentials, or host private reference libraries. Read the data-processing summary.
