Pinterest API接続は承認前の開発機能です

APIで取得するボード・ピン情報の保存、選択画像のOpenAIへの入力、保持・削除条件について、Pinterestへの明示的な確認が必要です。現時点ではこのAPI接続は有効になっていません。以下では、現在のローカルアプリの処理と、申請する接続の内容を分けて説明します。

1. 読み取る情報

現在のローカルアプリでは、利用者が接続したBrainVaultの必要なノート、選択した言葉、対話で確認した要件、利用者が指定した参照ライブラリ内の画像・メモ・出典を読み取ります。BrainVault自体には書き込みません。

Pinterest接続では、認証したアカウントのユーザー名を確認した上で、対象となる本人の公開・非公開ボードとピン、その画像・動画の表紙画像・説明・出典・ボード所属を読み取る予定です。本人が保存したピンには、他のクリエイターの作品も含まれます。PinterestのパスワードやブラウザのセッションCookieを収集する方式は使用しません。

2. 利用目的とAIへの入力

参照の検索・選抜、独自の構図と動きの設計、実装、評価と修正に利用します。必要なノートの内容、要件、選ばれた参考画像、出典、観測メモは、利用者が接続したOpenAIの制作エージェントへの入力になります。OpenAI上での取り扱いは、利用者の契約・設定と同社のポリシーに従います。本アプリ自体は、取得資料によるモデルの学習や微調整を行いません。

Pinterest API由来の情報については、保存とOpenAIへの入力の許可・条件を確認するまで、この処理を開始しません。利用者の同意だけで、Pinterestの許可を代替することはありません。

3. 端末内の保存場所

  • 参照ライブラリのフォルダー：利用者が設定した場所へ、取り込んだ参考画像、ノート、出典、ボード情報を保存します。
  • アプリの保存領域：設定、OAuthトークン、観測記録、制作の入力・出力・履歴を保存します。再試行時に参考が変わらないよう、同期時点の資料を複製する仕組みも実装しています。

認証情報は端末内の権限を限定したファイルへ保存し、他の利用者向けの配布物や制作AIへの入力には含めません。API資料の複製・保持を行う機能は、Pinterestから明示的な許可と保持条件を確認してから有効にします。許可前に無期限保存を正当化するものではありません。

4. 公開と共有

私有ノート、認証情報、参考画像を完成したウェブページへ自動で転載しません。公開用に確認した文章・リンクと、使用できる制作素材を区別します。ピンを保存・参照できることは、その画像を完成品へ転載できることを意味しません。配布パッケージに、運営者本人のアカウント認証情報を含めません。

5. 接続の停止と保存情報

Pinterestのアプリ連携設定で許可を取り消せます。ただし、認証の取り消しだけでは、端末内の既存資料や制作履歴は自動削除されません。API接続の開始前に、Pinterestが要求する保持・削除条件と、この処理の整合を確認します。

現在のローカル保存資料を消去する場合は、アプリの保存領域だけでなく、別に設定した参照ライブラリのフォルダーと、そのバックアップも確認する必要があります。OpenAIへ送信済みの内容や記録は端末内のファイルとは別であり、接続したサービスの契約・設定・削除手順で扱います。アプリの保存領域を消しても、これらすべてが消えるという説明は行いません。

6. この案内ページ

このページには、独自のログイン、資料のアップロード、AIへの送信、お問い合わせフォーム、広告タグ、アクセス解析タグを設けていません。アプリのアカウント接続やデータ処理は、この静的な案内ページ上では実行されません。ホスティング基盤による通信情報等の取り扱いは、提供者の規定に従います。

Data-processing summary

Feeling Design is a local app developed by ARCHECO. It reads user-selected BrainVault notes, the confirmed project brief and local reference files. The planned Pinterest integration verifies the authenticated account’s username and reads the owner’s public and secret reference boards and Pins, including Pins saved from other creators.

Selected images, attribution, observations and necessary brief or note content are provided to the user’s connected OpenAI production agent for original design inference. The app itself does not train or fine-tune models. Pinterest API data storage and transmission to OpenAI are subject to explicit Pinterest authorization; these activities are not currently enabled.

Local reference files are stored in the separately configured reference-library folder. App settings, credentials, project history and proposed per-sync archival copies are stored in app data. Disconnecting alone does not delete local files, backups or records already sent to an AI provider. The required retention, revocation and deletion conditions must be resolved before enabling the Pinterest integration. No claim is made that ordinary account consent or generic Trial approval grants exceptions to Pinterest’s restrictions.

This information site does not collect credentials or private reference files. Contact the operator.
