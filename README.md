# Feeling Design — Application information

This repository contains the application information and data-processing notice for Feeling Design, a local design research and website-authoring app developed by ARCHECO.

## Pages

- `docs/index.html` — Application overview and current integration status.
- `docs/privacy.html` — Data sources, AI inputs, storage locations, and connection/deletion limitations.
- `docs/styles.css` — Shared responsive styles.

The site is plain HTML/CSS, with no build step, third-party scripts, account login, analytics tags, or upload endpoints. GitHub Pages can serve the `docs` folder on the default branch. Relative links support a project-site URL.

## Scope

Only the informational website is maintained here. Application source, private reference images, BrainVault notes, account credentials, OAuth tokens, and local production histories are not part of this repository.

## Pinterest integration status

The planned integration requires Pinterest's explicit authorization for the described API data storage and OpenAI processing. These activities are not enabled. Generic Trial approval is not treated as permission for exceptions to Pinterest's restrictions. The notice describes current limitations rather than promising unimplemented deletion behavior.

## Changes

Propose updates through a branch and pull request. Check wording, links, desktop/mobile readability, and the absence of private material before merging.
